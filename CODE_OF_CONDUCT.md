# Code of conduct

## Expectations

Participants in issues, pull requests and other project spaces should treat each other respectfully. Welcome questions, explain technical disagreements with evidence, accept constructive feedback and respect privacy.

Harassment, threats, discriminatory language, sexual attention, personal attacks, doxxing and deliberate disruption are unacceptable. These expectations also apply when someone represents the project in another space.

## Reporting and enforcement

Report a concern privately to the [repository owner](https://github.com/0then0) using the email contact listed on that profile. If no private contact is available, open an issue asking for a private contact without posting names, personal information or incident details. Do not use vulnerability reports for conduct complaints.

The maintainer reviews reports and may request clarification, remove content, ask a participant to change their behavior, or restrict participation temporarily or permanently according to severity and repetition. Reports and personal information should be shared only as needed to address the concern. Decisions should explain the applicable behavior and restriction without exposing private details.

These guidelines apply to all contributors, including maintainers. They are adapted from the principles of the [Contributor Covenant](https://www.contributor-covenant.org/).
